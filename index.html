Survey Builder

JSON — schema Google Forms API v1

Nguồn dữ liệu là các file trong surveys/. Sửa nội dung nên sửa ở authoring/<id>.mjs rồi chạy node build.mjs; ô dưới đây để thử nhanh. Chấp nhận 2 định dạng: (1) chuẩn Forms API v1 — { info, items[] } với questionItem, questionGroupItem, pageBreakItem, textItem, skip-logic qua options[].goToSectionId / goToAction; (2) định dạng gọn — { title, items:[{type,title,choices,…}] }. Nút Tải JSON xuất bản đã strip field mở rộng _exclusive, dùng được ngay với forms.batchUpdate.

Apps Script — tạo Google Form thật

  1. Bấm Copy, mở script.google.com → New project.
  2. Xoá hết nội dung Code.gs, dán vào, đặt tên project rồi Save.
  3. Chọn hàm createForm → Run. Lần đầu Google hỏi quyền, chọn Review permissions → Allow.
  4. Mở Execution log để lấy link edit & link điền của form vừa tạo.
